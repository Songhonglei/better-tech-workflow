## 阶段

| 阶段 | 核对与操作 | 停止条件 |
| --- | --- | --- |
| 原证书 | 账号、域名、Bucket、地域、资源 ID、当前绑定证书 ID/精确期限和时区 | 超过阈值、绑定不明、缺时间或入口映射不一致 |
| 复用 | 查询已有额度、订单、申请中实例、可用新证书、部署任务 | 候选不唯一或前次提交结果未知 |
| 免费购买 | 个人测试证书→免费版→90 天→1 张→无付费附加项；最终应付 CNY 0.00 后才下单 | 非免费版、收费/价格未知、额度不足、未授权 |
| 申请签发 | 已绑定本域名或未绑定实例，精确域名、已有联系人，完成授权内验证，等已签发 | 域名不匹配、额外授权、验证/签发失败或超时 |
| 部署选择 | 选核对过的新证书，下一步选本域名原有 OSS 资源 | 未签发、SAN 不符、未生效/过期、原证书变化 |
| 预览 | 一个域名、一个目标资源、新旧证书、立即部署、零元且无付费次数 | 额外资源、费用、缺替换确认；模拟一律不提交 |
| 提交验收 | 提交一次，查任务，回读绑定，检查公网证书和 HTTPS 基线 | 结果未知先查询；绑定已换但公网未更新记“已部署，待生效” |

“预览并提交”在不同版本可能直接写入，先核对当前语义，模拟不点击。表中是业务顺序，具体控件按当前页面观察，不编造选择器。购买不等于签发，申请域名和部署时选择域名资源分别核对。

当前 V2 实测：从资源行“部署证书”进入向导，等待实际加载后选“个人测试证书（原免费证书）”，列表的“资源ID”可能是订阅实例 ID，不是数字证书 ID。用实例详情建立实例 ID → CertIdentifier 的对应关系。新证书名称和完整 CertIdentifier 必须在最终预览再次一致。

“预览并提交”会生成任务预览及任务实例标识；将它作为可能写入阶段记录。等待预览真实出现目标行，核对一个资源、一个证书、消耗 0 次部署额度、立即部署后，才提交一次。提交后暂显“待部署”可能是旧状态；先刷新已创建任务并查询，不能因页面仍有“立即部署”就再次启动。实测后台已成功时该按钮会返回 `OperationDenied.NotSupport / job status can not change for success`；此时只读核对原任务与实际绑定，不新建任务、不重复部署。

## 域名与证书

- 一次只处理一个精确主机名，根域与 www 不互相扩展授权。免费版不支持通配符和任意多域名；特殊后缀按当前官方/页面限制停止，不维护易过期黑名单。
- 新证书 SAN 必须精确包含目标域名，不能只比较名称；完整期限按 [本地核查线](policy-input.md) 与 90 天比较，实际到期时间须晚于旧证书，剩余时间超过阈值；异常就停止复核。
- 公网探测使用域名 SNI。`inspect_tls.py` 在信任失败时仅为诊断读取公开证书，返回 `verified=false`；不能据此通过安全验收。通过控制台指纹/序列号及入口映射确认与当前绑定一致；无法确认时停止。旧证书已过期可进入续期，但新证书最终验收不可关闭验证。
