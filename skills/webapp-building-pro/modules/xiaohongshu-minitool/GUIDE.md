# 小红书小工具

开发或修改时交付同一版本的 H5 预览与小红书 ZIP。Kimi 有真实版本工具时保存版本卡；Codex、WorkBuddy 等使用当前宿主的本地/Web 预览，不强求 Kimi 工具。小红书真机体验、送审与正式发布分别验收。

## 按当前目标进入

- 开发、改造、离线兼容、打包或产物审计：读 [builder/GUIDE.md](builder/GUIDE.md)，保留原项目及用户资料。
- 登录、查询、上传、真机预览或送审：读 [cli/GUIDE.md](cli/GUIDE.md)，使用 redapp CLI；CLI 不能放入交付 ZIP。
- 用户只授权登录和只读查询时，不进入上传、预览或送审。只读测试不需要创建演示小工具。

## 只读验证与恢复

1. 用版本门禁确定实际 redapp 入口及 prod/beta，不永久改 npm 配置。已有同环境登录优先复用；业务回执不足或登录失效再登录，不能仅凭 whoami 判断业务通过。
2. 使用本次已分配的 source。当前会话已有 config/list 成功的来源、环境与授权时直接复用；仅换接入方、环境或接口明确拒绝时重新核对，不反复询问。thirdAgent 是历史实测来源，不是所有账号的默认值；不能盲换 source 去寻找作品。
3. 以真实 config 和 list 回执验证。list 成功但 total=0 表示当前账号、环境和来源下没有可见应用；标记「只读查询通过、列表为空」，不判定登录失败，不猜 appId 调 status/history，也不为验证继续而创建作品。
4. 操作记录只保存环境、来源、版本、完成阶段和无凭证回执，使用 [CLI 恢复约定](cli/references/session.md)。未知写入先只读查询，不重复上传、创建预览或提交。

## 开发与双交付

按 builder 规则实现离线 H5；核心流程适合手机触摸，处理顶部/底部安全区、输入法、弹窗、滚动和返回。普通浏览器能使用通用 Web 功能；缺少 window.xhs 时，小红书专属能力提示到真机体验，不伪造成功。

构建后审计最终产物，再从同一份代码提供 H5 预览和合格 ZIP。H5 使用当前宿主真实预览或版本工具，缺少托管工具时交付可用本地预览及其限制；仅 Kimi 环境需要其版本卡。H5、ZIP 和小红书真机是不同交付物；保存失败要说明，不能以另一个产物冒充成功。用户已有验证过的包和素材、仅需平台操作时直接复用，不重新开发。

## 登录二维码

从同一条 CLI PROMPT 读取 userCode、expiresInSeconds、qrCodePath、authorizeH5Url，完整展示授权码、有效期、原生 PNG 和备用入口；字段缺失如实说明，不拼接或重绘。Codex 用绝对路径 Markdown 图片展示。保持原登录进程等待扫码和手机输入授权码，不另起登录；以该进程 RESULT_JSON.status=ok 确认登录成功。凭证只由 CLI 存在自己的用户目录，不打包或写操作记录。

## 上传、预览与送审

用户已要求上传、预览或发布时，Agent 按 CLI 路线完成，不默认把手动上传教程交回用户。自动从当前项目起草名称、简介、版本、类目与权限；缺图标/封面时按已有页面生成并校验格式、尺寸和体积。先用真实 config/source 核对，再按当前 CLI 的 dry-run/confirm 协议执行；有授权不重复询问。

预览使用本次已校验的 ZIP、名称、版本和图标，交付 CLI 原生二维码与 previewUrl。二维码生成或用户仅说「已扫码」不等于真机通过。先让用户扫码体验，再通过当前宿主可用提问工具合并确认：「本次预览是否通过，并确认提交审核？」提供确认和需要修改两种选择；无提问工具时用普通对话等待，不调用不存在的 ask_user。返回 No preference、超时、沉默或模糊回复不算确认。

已有明确针对本次预览及送审的确认，且代码包/资料未变化时不重复问。只有「预览通过」但未授权送审时，只记录预览通过；合并提问上下文中的「可以」「没问题」「继续送审」等明确答复可作为有效确认。包、版本、图标等待审内容变化时重新构建、核验和预览。

执行后简洁报告当前阶段，必要二维码和链接优先；openId、planHash、fileId、MD5 等留在私密操作记录，不堆在交付文案。submitted 只代表接收送审，不代表审核通过或正式发布。CLI 无删除、下架或下载源码能力时不得虚构命令；发布后挂载笔记由用户按平台能力完成，不能代发未获授权的内容。

## 实测范围

历史 prod CLI 1.0.5 真实登录、config、list 成功，当前来源下 0 个应用，无上传或其他业务写入。该结果可用于定位已完成阶段，不能替代新任务当前版本门禁、账号和环境检查，也不代表真机、送审或发布已验收。
