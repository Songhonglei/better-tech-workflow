# 极简计时器

**展示优先级**：本模版是移动端（窄屏）优先展示的案例。向用户预览或演示本模版时，优先用窄屏（手机宽度）视口展示效果；需要展示桌面端布局时再切换到宽屏。

界面语言由用户 query 的语言决定。本包为中文单语版：所有界面文案集中在
`i18n.js`，换成另一种语言只需整体替换这一个文件。

**平台运行约定（不要破坏）**：本模版是 Vite + React 纯静态站。预览执行
`npm run dev -- --host 0.0.0.0 --port <平台端口>`；发布执行 `npm run build`。
`src/index.html` 是开发入口，构建同时更新 `dist/` 和包根 `index.html` / `assets/`，
包根可直接由静态服务器打开；修改源码后须重新构建。发布只上传 `dist/` 内容，
不需要服务端、数据库或 `boot.js`。保留 `dev` / `build` 两个 script；字体和背景
保存在 `public/assets/`，不使用外部字体。依赖由 `package-lock.json` 锁定，
解压后执行 `npm ci` 即可恢复；`node_modules` 不随包交付。

动手前先用 ask_user 问几个问题：

- **是否需要做全栈应用**（即持久化数据存储，例如保存计时历史或常用时长预设；
  需要服务端与数据库）。本模版默认纯前端，计时数据不持久化；主题选择仅保存在本机浏览器。
- 主题色：保持现在的彩色静态背景与透明玻璃风格，还是换成其他颜色（`style.css` 的
  `--accent` 与 `.sector` 控制按钮和磨砂色调）。
- 默认倒计时时长：当前默认 10 分钟，是否调整（`app.js` 里 `timers.countdown`）。

用户不答就直接加载默认文件。

## 这个网站是什么

一个极简风格的计时器，首次打开默认明亮模式。右下角太阳 / 月亮按钮切换明暗，
浏览器会记住用户选择；时间模式下同样可切换主题。顶部毛玻璃胶囊切换三种模式：

- **倒计时**：默认 10 分钟，点按数字弹出 iOS 滚轮设置时 / 分 / 秒
  （分钟与秒 60 个数循环滑动），毛玻璃扇形的圆心角即剩余时间百分比；
- **秒表**：正计时，支持分段计时，分段记录带编号列在时钟正下方，
  最多 20 条、可上下滑动；
- **时间**：实时显示当前时间，扇形随秒针扫动。

背景采用一张 3840×2160（16:9、4K）的静态 WebP 图片，保留横向模糊和暖橙、
蓝紫、浅灰蓝的色彩分区。裁去原图顶部 324px（15%）白色区域后，将剩余画面
纵向拉伸回 2160px。所有屏幕共用同一方向的图片，通过 `object-fit: fill` 按屏幕
宽高铺满，不留空白、不旋转；玻璃折射按横纵两轴分别取样，与拉伸后的背景对齐。
表盘直径与顶部模式切换胶囊的实际宽度一致，数字按直径等比缩放。
表盘是一个 iOS 液态玻璃圆盘：整圆透明（边缘高光 +
细描边），进度扇形为毛玻璃质感，两条径向边缘锐利。

文件结构：

```
index.html      可直接运行的构建入口（自动生成，不直接编辑）
assets/         包根构建资源（自动生成）
src/index.html  Vite 开发入口与首屏主题恢复
src/App.jsx     React 页面结构与挂载生命周期
src/main.jsx    React 启动入口
style.css       页面布局、主题、玻璃与控件样式
app.js          计时、模式切换、滚轮与分段记录，卸载时清理监听和动画
glass.js        玻璃折射与高光，卸载时清理 Canvas 和观察器
i18n.js         全部界面文案
public/assets/  4K 静态背景与自托管字体
scripts/        Vite 构建与预览启动脚本
vite.config.js  开发目录、静态资源和构建输出配置
package*.json   脚本、依赖及锁定版本
dist/           可直接部署的构建产物
```

可能被改成：厨房计时器、番茄钟、运动间歇计时、演讲倒计时等。
用户只是想看就直接加载默认文件。

## 技术要点

表盘分四层：`.dial` 保持中心透明并投射柔和阴影；`.sector` 用均匀的浅色半透明蒙层
和 `backdrop-filter: blur(18px)` 表现磨砂，conic mask 的圆心角代表剩余时间；
`.glass-refraction` 在毛玻璃层下采样背景并沿表面法线产生折射位移；
`.glass-rim` 在最上层绘制窄边缘和对向高光，避免遮盖进度扇形。按钮折射区深入圆角半径的 96%，覆盖接近整个表面；表盘深入半径的 72%，
折射位移向中心缓慢衰减，最大位移分别为 60px 与 44px，带轻微色散；不捕捉任意页面内容。中心毛玻璃仍用 CSS backdrop-filter 模糊。
表盘容器与进度层都使用圆形裁切，进度层内缩 1px，滤镜输出不会超出表盘。
没有进度颜色渐变或径向衰减。0° 完全透明，360° 完整磨砂。
背景像素以最多 2048px 宽度共享采样缓存，原始显示图片仍为 4K；边缘在初始化、背景加载、尺寸或位置变化时重绘；
切换胶囊移动时同步更新折射，静止后停止，像素密度最多 2 倍；不支持 Canvas
时保留 CSS 玻璃边缘。计时数字采用原生系统字体和白色前景，位于玻璃层之上，始终清晰。开源许可随
`THIRD_PARTY_NOTICES.md` 打包保留，构建资源采用内容哈希用于缓存更新。
滚轮选择器用 scroll-snap + 3 组数据循环（滚近边界时无感跳回中间一组），
圆柱效果按每行与轮中心的距离计算 rotateX 与透明度。
字体 `font-feature-settings: "tnum"` 保证跳秒时数字宽度不抖动。

主题在首屏绘制前读取 `localStorage` 的 `minimal-timer-theme`；未保存或读取失败时默认明亮。
背景和折射像素使用相同的亮度 / 饱和度滤镜，设置面板、分段记录与图标同步切换。
主题按钮支持键盘，焦点位于按钮时空格不再触发全局计时快捷键。
