# 北风 · 管理后台 — 使用说明

这是一个中文管理后台（dashboard）网站。界面语言跟随用户的 query 语言：用户用什么语言交流，呈现给用户的界面文案就用什么语言（本仓库默认中文内容，可按需替换为用户的语言）。

## 第一件事：问用户

加载网站前，先用 ask_user 问几个关键问题。**必问**：

1. **是否需要把网页变成全栈应用？** 即是否需要持久化的数据存储（数据库 + 后端 API）：现在的数据全是前端内置的演示数据，刷新即还原；变成全栈后，订单、客户、商品等数据会真实保存在数据库里，可以增删改查。

再按网页内容挑几个问，例如：

2. 这个后台用来管理什么业务？默认是电商运营（订单 / 商品 / 客户 / 发票 / 收入），可以换成 SaaS 订阅、物流、内容平台等任何领域 —— 换领域意味着替换演示数据、文案和部分页面结构。
3. 品牌与外观：默认品牌名「北风」，深色主题优先（可切换亮色），琥珀橙强调色。要不要换品牌名、默认明暗、强调色？
4. 地图的市场范围：默认展示中国城市与全球航线，要不要换成用户实际经营的城市 / 国家？

如果用户不回答任何问题，就直接加载默认网站文件。

**重要（dashboard 类默认行为）**：除非用户明确说只要静态网站，否则在线上使用时，加载完网页文件后，默认继续用 backend-building skill 把后端（数据模型、API、持久化存储）补全，让页面里的数据真实可读写。

可选：如果符合用户的需求，你可以使用图像和视频生成工具。

## 这个网站是什么

「北风 · 管理后台」—— 一个单页的管理控制台，左侧导航 + 顶栏（搜索 / 主题切换 / 通知弹层），八个真实页面共用同一份演示数据：总览（KPI 数字滚动、世界地图热点、收入趋势、流量来源、近期订单、动态流）、分析（获客漏斗、留存热力图）、报表、客户、订单、商品、发票、设置。所有数据是种子化的演示数据（刷新不变），表格可排序、可搜索、可分页，地图上的城市热点可以点击筛选订单表。

## 技术要点（改代码前先读这些文件）

- **命令式图表与 React 的边界**：ECharts 实例由 `src/lib/kit.js` 的注册表持有，`Kit.chart()` 建图时合并 `Kit.base()` 的主题配色；切换明暗主题时 `retheme()` 原地重建所有图，React 组件（`components/Chart.tsx`）只递一个空 div、卸载时 `release()`。新增图表照这个模式走，不要让 React 管图表内部状态。
- **WebGL shader 背景**：`src/lib/fx.js` 的 `aurora()` 是全屏 fragment shader——三重 domain-warped fbm（fbm 套 fbm），颜色全部实时读 CSS token（`--fx-1/2/3`、`--bg`），40% 分辨率渲染、30fps 封顶、有序抖动消色带、自带 vignette；离屏 / 切后台 / 用户要求减少动效时自动停帧。面板半透明 + backdrop blur，让这层光透上来。fx.js 里还有 constellation / radar / topo / ridgeline / hudgrid / gauge / trail 一整套同款 canvas 特效工厂，可复用。
- **点阵世界地图**：`src/lib/worldmap.js` + `src/lib/geo.js`。陆地不做点包含测试，而是把 TopoJSON 多边形一次性栅格化成位图，再按「面积均匀」的经纬格采样出点阵；等距圆柱投影两轴同比例，高度方向裁掉极区。航线是大圆插值 + 向极点弯的二次曲线，带日界线接缝保护；虚线表「存在连接」，移动亮头表「正在运输」；热点用径向渐变 + 双环脉冲表强度，点击热点回调 `onPick` 驱动下方表格筛选。
- **设计约束**：发丝线不投影；数字一律等宽 + tabular-nums；全站只有一个强调色，只花在当前项 / 主操作 / 最重要的那条数据上；一切颜色走 CSS token，不写死 hex —— 这是主题切换能工作的根本原因。
- **演示数据确定性**：`Kit.rng(seed)` 伪随机序列种子化，所有图与表共享同一序列，截图可复现；要换真实数据时从 `src/lib/data.js` 下手。
