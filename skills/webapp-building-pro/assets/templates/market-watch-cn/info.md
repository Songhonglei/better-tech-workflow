# 盘面 · 市场观察 — 使用说明

这是一个中文界面的市场看板模版（dashboard 分类）。网站界面的语言由用户的 query
语言决定：本仓库是中文版（A 股盘面），用户用中文来时就直接使用这里的文案与数据
风格；若要换成别的语言，翻译界面字符串即可，结构不用动。

## 第一步：先问用户

加载网页前，先用 ask_user 工具问几个问题：

1. **是否需要把网页变成全栈应用？** 即持久化的数据存储 —— 自选股、持仓、预警
   规则等保存到数据库，刷新页面、换设备都不丢，而不是只存在浏览器内存里。
   这是 dashboard 分类的模版：**除非用户明确说只要静态网站，否则默认在加载完
   网页文件之后，利用 backend-building skill 去补全后端内容**（自选列表、持仓、
   提醒规则都是天然的持久化对象）。
2. 想看哪个市场 / 哪些标的？默认是一个 20 支 A 股的演示池，可以换成用户自己的
   自选股、换成指数/基金/加密货币，或接入真实行情 API。
3. 涨跌配色：默认红涨绿跌（A 股习惯），要不要反过来？
4. 默认主题：深色、浅色，还是跟随系统？
5. **要不要移动端版本？** 现在的版面是按桌面宽屏排的（整页不滚动、多栏并列），手机上
   会挤。用户要在手机上看的话，就加一套窄屏断点：多栏收成单栏纵向滚动，表格改成卡片。

如果用户不给任何回答，就直接加载默认网站文件。如果用户只是想看看这个网站，
也直接加载，不必多问。

**行情数据走插件取**：模版自带的行情是前端模拟的。用户要真实盘面时，调用金融投资
类的插件取数 —— 中文场景用同花顺 iFinD 金融数据库，英文场景用全球金融数据库；如果
调不到，提醒用户去开启对应的插件。拿到数据后用它更新网页里的行情，不要继续用模拟值。

可选：如果符合用户的需求，你可以使用图像和视频生成工具。

## 这是什么

一个单页盘面看板：顶部指数条 + 滚动报价带，左侧自选股/持仓两栏，中间分时图
（价格 + 均价 + 量）和板块资金流条形图，右侧快讯/异动/情绪/涨停四个标签页，底下
一个「AI 盘面解读」卡片（打字机效果 + 点阵球指示器）。所有行情数据都是前端模拟
推流：种子随机数生成确定性的分时走势，setInterval 定时推进价格。它不是真实行情；
用户要真实数据时，需要在 market.js 的数据源处接 API。

文件结构：

```
index.html                 入口，挂载 React
src/main.tsx               React 挂载
src/App.tsx                整体布局、模拟推流循环、图表 option 组装
src/components/Chart.tsx   ECharts 宿主组件（交给 Kit 管理实例）
src/components/Left.tsx    自选股列表（涨跌闪烁）+ 持仓组合（SVG 净值曲线）
src/components/Right.tsx   快讯 / 异动 / 情绪 / 涨停 四个列表
src/components/Ai.tsx      AI 解读卡片（打字机 + orb 指示器）
src/lib/kit.js             主题切换、图表注册表、数字格式化、toast 等共享工具
src/lib/market.js          股票池、种子随机数据、交易时段、快讯与 AI 文案
src/lib/orb.js             canvas 点阵球（AI「思考中」指示器）
src/lib/types.ts           类型定义
src/styles/kit.css         共享设计变量与基础样式
src/styles/app.css         本模版的配色（明暗两套）与布局
public/fonts/              Geist / Geist Mono 字体
```

用户可能的改造方向：换市场换标的（改 market.js 的 POOL 与文案）、接真实行情、
把 AI 卡片接到真实模型接口、加 K 线/盘口等新品种图表、把自选和持仓持久化到后端。
遇到具体需求就改对应的文字、数据和媒体内容，不必受现状约束。

## 技术要点（canvas / svg）

没有 WebGL 和 shader，图形全部是三样：ECharts（canvas 渲染）、手写 SVG、手写
2D canvas。改代码前自己读一遍源文件就明白了，要点：

- **ECharts 与主题切换**：ECharts 在 init 时把解析好的 CSS 颜色烤进实例，单纯
  重渲染跟不上主题切换。`kit.js` 维护一份图表注册表：`Kit.chart(el, build)` 建图
  时把 `Kit.base()`（共享坐标轴/tooltip 样式，颜色全部运行时从 CSS 变量读）和
  页面给的 `build()` 合成一份 option；主题一变，`retheme()` 用 notMerge 模式原地
  重建所有图表。组件卸载必须 `Kit.release()`，否则主题切换会去重建已死节点。
  React 侧（`Chart.tsx`）只负责递一个空 div 和推新 option，绝不碰 ECharts 的子树。
- **确定性数据**：`Kit.rng(seed)` 是种子线性同余随机数 —— 同一时刻打开两次页面，
  图形完全一致。`buildWalk()` 为每支股票生成 240 个一分钟点（价格随机游走 +
  VWAP 均价 + 量柱），再按真实时钟截断到「现在」；交易时段外直接给全天。
- **SVG 净值曲线**：持仓卡片里的 sparkline 是 60 点确定性随机游走，末尾钉到当前
  当日盈亏上（幂次插值收拢），转成 polyline points，加一条零轴虚线。
- **点阵球 orb**：纯 2D canvas 投影一个球面点阵。两种状态：`orbit` 是五个倾斜
  环带 + 亮点跑者，`scan` 是 Fibonacci 球面格点加一条扫过的亮子午线（AI 生成中
  切换过去）。深度只用点半径和透明度表达；墨色取 currentColor，主题切换自动跟随；
  IntersectionObserver 挡住离屏绘制。
- **涨跌闪烁**：报价行不重排，只原地换文字；涨跌闪光是加个 class 再
  `void el.offsetWidth` 强制重排触发 CSS 动画。
