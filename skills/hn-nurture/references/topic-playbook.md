# 选题方向手册

> 所有个人背景与方向偏好从配置读取，不硬编码。
> 配置项见 `~/.config/hn-nurture/profile.env`（用 `scripts/setup_profile.sh` 生成）。

## 读取配置

执行任何选题前，先读取用户档案：

```bash
cat ~/.config/hn-nurture/profile.env 2>/dev/null || echo "NOT_CONFIGURED"
```

| 变量 | 用途 |
|------|------|
| `HN_USERNAME` | HN 用户名，flag 自检定位评论用 |
| `USER_ROLE` | 职位角色，判断能写什么一手经验 |
| `USER_EXPERTISE` | 专业领域，选题方向锚点 |
| `TOPIC_DIRECTIONS` | 允许的方向全集 |
| `TOPIC_STRONG` | 强优势方向，优先选 |
| `TOPIC_WEAK` | 需谨慎方向，必须挂具体经历 |
| `TOPIC_AVOID` | 明确排除的方向 |

**若配置不存在**：提示用户先运行 `bash scripts/setup_profile.sh`，不要凭猜测选题。

环境变量优先级：`HN_USERNAME` 等环境变量 > `profile.env` 文件。

## 选帖的唯一铁律

**用户能贡献"我做过 / 我见过"的一手信息，而不是复述文章观点。**

读到 `USER_ROLE` 和 `USER_EXPERTISE` 后，反推这个人在哪些话题上有别人没有的信息，优先选那些帖子。

## 方向分级的使用方式

### 强优势区（`TOPIC_STRONG`，优先选）

通常是用户的职业主场。典型的高价值角度：

- **企业软件 / CRM / B 端产品**：需求调研里听到的真话、上线后被绕过的流程、权限设计的两难、各部门数据口径打架
  - 高价值切入：实施落地的人因问题（不是技术能不能，是组织愿不愿）、采购决策的真实逻辑、为什么企业软件体验天然差
- **AI coding / AI + 工作流**：Agent 在企业场景落地的坑、AI 输出不可追溯怎么办、哪些环节人必须签字、提效到底怎么测量
- **软件开发**：带团队的技术取舍、技术债、老系统改造（要挂个人经验，不写通用技术科普）

### 需谨慎（`TOPIC_WEAK`）

典型如教育、个人成长类。**天然容易写成"道理 + 总结"的空话，是 AI 味重灾区，社区极度敏感。**

- 必须挂具体场景：某次真实对话、某个具体的人、某段具体经历
- 不写抽象感悟，只写发生了什么

### 排除（`TOPIC_AVOID`）

默认建议排除泛技术怀旧类（复古硬件、老游戏、老式计算机、老工具）——这类话题与个人职业身份通常无关，写不出一手经验，只能靠"感慨 + 提问"撑，写多了措辞趋同，正好撞上模板检测。

## 高价值角度的通用挖掘法

读完全部评论后问三个问题：

1. **所有人都同意的是什么？** —— 那是安全的废话，不要重复
2. **大家都在讲技术实现，谁在讲人和组织？** —— 通常是空白
3. **这个产品在受监管行业（财务、法务、医疗）会遇到什么问题？** —— 评论区极少有人提，是职业背景带来的护城河

**实测有效的稀缺角度类型：**

- 可追溯性 / 审计 / 合规 —— 几乎没人提，但受监管行业是硬需求
- 数据本身的"脏" —— 企业内部事实不唯一、口径打架
- 实施落地的人因问题

## 高风险写法（社区会 flag）

- ❌ "From building..." / "I built..." 开头 + 产品功能罗列 → 疑似隐式推广
- ❌ 4 段固定结构 + 编号列表 → AI 模板高敏
- ❌ AI 高频模板句："This resonates..." / "The key insight..." / "The trade-off is real..."
- ❌ 抽象道理 + 总结式收尾（教育/成长类尤其容易踩）
- ❌ 复述文章观点而不加任何自己的信息
- ❌ 涉及政治、AI 伦理等撕裂性话题的高热帖

## 低风险写法

- 从一个具体的失败 / 踩坑切入
- 承认不确定
- 结尾抛一个真问题给作者或社区
- 2-4 句，口语化

> ⚠️ 以上仅为**风险特征清单**，供判断使用。
> **不要据此代写或改写用户的文字** —— 那是本 skill 的最高红线。

## 热度参考

| 评论数 | 建议 |
|--------|------|
| < 50 | 安全区，优先 |
| 50 - 150 | 可选，避开争议话题 |
| > 150 | 一般避开 |

Launch HN / Show HN 帖可以评，但**绝不能写成自我推广腔**。创始人通常在线回复，深度问题回报率高。
